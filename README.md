# 宝宝学英语 · 在线更新分发源

本仓库是「宝宝学英语」Android App 的 **OTA（在线更新）分发源**，公开只读，不含任何源码逻辑之外的私密信息。
App 主仓库为私有仓库，与此处分离。

## 它是怎么工作的

App 的全部界面与内容都在一个 `app.html`（约 230 KB）里，视频、音频等大资源随 APK 一起安装、不参与更新。
所以一次在线更新只需下载这 230 KB，秒级完成，用户不必重新安装。

```
App 启动
  └─ 加载器 index.html 判断：用 APK 内置版，还是用已下载的新版
       └─ 应用运行后，后台每 6 小时检查一次本仓库的 manifest.json
            └─ 有新版本 → 下载 releases/app-x.y.z.html
                 → 校验 SHA-256 与页面完整性
                    → 存入本地，提示「立即重启」生效
```

安全兜底：新版本若连续 2 次启动失败，加载器会自动回滚到 APK 内置的稳定版本。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `manifest.json` | 更新清单，App 每次检查更新读取它 |
| `releases/app-x.y.z.html` | 各版本的应用更新包 |

### manifest.json 字段

| 字段 | 说明 |
| --- | --- |
| `version` | 最新版本号，需高于用户当前版本才会触发更新 |
| `file` | 更新包相对路径 |
| `size` | 字节数 |
| `sha256` | 更新包校验和，不匹配则拒绝安装 |
| `notes` | 更新说明，会显示给用户 |
| `minNativeVersion` | 该更新包所需的最低 APK 版本 |

## 如何发布新版本

在主仓库的 `kids-apk/` 目录下执行：

```bash
./ota-release.sh 1.1.1 "新增 5 首古诗"
```

脚本会自动完成版本号写入、语法自检、上传更新包、生成 manifest 并推送。

## 什么情况必须重新打 APK

- 新增/替换视频、音频等大体积资源
- 改动原生代码或新增 Capacitor 插件
- 改动加载器 `index.html` 本身

其余改动（文案、样式、题目、新板块、交互逻辑）都可以直接走在线更新。
